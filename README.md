# Qualcomm Company Website

A modern, full-stack website for Qualcomm with story-based landing page, smooth animations, and multiple pages.

## Features

- 🎨 Story-based landing page with GSAP animations
- 📱 Fully responsive design
- 🔄 Smooth page transitions
- 📧 Contact form functionality
- 💼 Careers and job applications
- 🎯 Product showcase
- 📰 Innovation hub
- 📝 Newsletter subscription

## Tech Stack

**Frontend:**
- HTML5
- CSS3
- Vanilla JavaScript
- GSAP (GreenSock Animation Platform)

**Backend:**
- Node.js
- Express.js
- EJS Template Engine

## Installation

1. Clone the repository
```bash
git clone https://github.com/logesh360/qualcomm-company-website.git
cd qualcomm-company-website
```

2. Install dependencies
```bash
npm install
```

3. Start the server
```bash
npm start
```

4. Open browser and navigate to `http://localhost:3000`
